# משפטי — מה פורסם ומה עוד פתוח

**הנוסח הפורסם חי באתר, לא כאן.** הדפים ב-`web/app/legal/` הם המקור היחיד:
`/legal/terms`, `/legal/influencer`, `/legal/privacy`, `/legal/accessibility`.
שני עותקים של טקסט משפטי תמיד נפרדים זה מזה, וטקסט משפטי שנפרד הוא בדיוק
הבעיה שהוא נועד למנוע. הקובץ הזה מחזיק רק את מה שצריך לשאול עורך דין.

כל הדפים נושאים באתר הודעת "טיוטה" גלויה, שיורדת כשהבדיקה תסתיים.

## שאלות לעורך הדין

### תנאי שימוש
1. האם המודל — תיווך בין עסק למשווק בתמורה לאחוז ממכירה — מחייב רישיון,
   רישום או כפיפות רגולטורית כלשהי.
2. סעיף הגבלת האחריות: להתאים לדין הישראלי, לרבות סייגים שאינם ניתנים להתנאה.
3. היררכיית ייחוס המכירה (סעיף 2) — האם היא אכיפה כפי שנוסחה.

### הסכם משפיען
4. **חובת הגילוי הנאות** — מי נושא באחריות כלפי הרשות להגנת הצרכן: הפלטפורמה
   שמייצרת את הודעת השיתוף עם הגילוי, המשפיען שמפרסם, או העסק. הפלטפורמה
   משבצת את הגילוי אוטומטית בכל הודעת שיתוף; האם זה מספיק.
5. ניכוי מס במקור: חובות הפלטפורמה כמשלמת, והמסמכים הנדרשים מהמשפיען לפני
   תשלום ראשון (אישור ניהול ספרים, פטור מניכוי).
6. ביטול רטרואקטיבי של עמלות שנצברו בגין הפרה — האם אכיף.

### פרטיות
7. מזהה הקונה נשמר מגובב בלבד (SHA-256 עם pepper סודי מחוץ לבסיס הנתונים),
   ואינו ניתן לשחזור מעשי. האם הרישום עדיין "מידע אישי" לעניין חוק הגנת
   הפרטיות ותיקון 13, ומהן חובות היידוע שנותרות על העסק ששולח את המזהה.
8. האם נדרש רישום מאגר מידע.

### נגישות
9. אישור נוסח הצהרת הנגישות מול תקנה 35, ופרטי רכז הנגישות לפי מבנה החברה
   כשתוקם. הבדיקה הטכנית תועדה ב-`docs/accessibility.md`.
